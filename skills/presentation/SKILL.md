# Consult

Use the `/communicate` skill to communicate the user. Show your concerns, the consequence and the recommended actions but not limit to these.

**MUST:**

1. You **MUST** ask with the tool dedicated for asking user questions **IF** you come to ask the user for questions **AND** the tool is available.
2. You **MUST** generate an illustrated HTML document instead of respond within the conversation **IF** text alone may be tedious or ambiguous. The HTML document could contain annotated illustrations, animated diagrams, scrubbable interactive animations, interactive diagrams, interactive simulations, explorable explanations, directional arrows, numbered callouts, and concise explanations.
