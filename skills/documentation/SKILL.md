# Documentation

Use the `/communicate` skill to document. Visualize necessary parts with Mermaid syntax if it can improve the comprehensiveness.

**MUST:**

1. You **MUST** use industry standard and established terminologies in the relevant fields.
2. You **MUST** follow the communication consistency rules in `/communicate` to guarantee communication consistency across conversations.

**MUST NOT:**

1. You **MUST NOT** invent termonologies on the fly.
2. You **MUST NOT** write condensed sentences. Instead, write bullet points with each item is a complete sentence.
